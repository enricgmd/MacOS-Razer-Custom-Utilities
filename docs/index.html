Razer Hardware Utilities for macOS Intel

Unlock macro keys and special buttons of your Razer devices on Intel-based macOS platforms.

Download latest release View source on GitHub

Built for the controls macOS misses

This is not a full Synapse replacement. It focuses on making supported Razer hardware expose its useful extra controls on Intel Macs, then letting you assign them to practical local actions.

BlackWidow macro keys

Use M1-M6 as assignable macOS controls for shortcuts, apps, scripts, folders, and system actions.

DeathAdder extra buttons

Use side buttons and top buttons, with automatic F15/F16 setup for the DeathAdder V2.

Native macOS utility

Built in Swift with IOKit HID inspection, SwiftUI, local event taps, and a menu bar workflow.

Keyboard key swapper

Create simple key remaps and keep them running alongside the Razer-specific controls.

Raw event viewers

Inspect keyboard and mouse HID events when adapting the project or debugging hardware behavior.

Supported hardware

The project is intentionally narrow and currently targets the exact devices below.

product-id=0x0293
